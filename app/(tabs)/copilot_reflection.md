# Copilot Reflection

## How I Used GitHub Copilot

I used GitHub Copilot to help me add a pie chart to my expense tracker app. Copilot helped me:
- Import the chart libraries
- Write functions to prepare my expense data for the chart
- Create a button to show and hide the chart
- Add styling for the chart components

## One suggestion Copilot gave that I changed or rejected, and why.

Copilot suggested using `db.allAsync()` to get data from my database, but that was wrong. The correct function name is `db.getAllAsync()`. I had to change this myself to make it work.

## How Copilot Saved Me Time or Effort

Copilot wrote the `getBarChartData` function for me automatically. It organized my expenses by date and sorted them, which would have taken me much longer to figure out on my own.
